# vovoscan desktop

Installers for the vovoscan desktop app: macOS (Apple silicon and Intel), Windows and Linux.

Download the latest from [Releases](../../releases/latest), or from [vovoscan.com](https://vovoscan.com/#apps), which picks
the right one for your computer.

The macOS installers are signed and notarized by Apple: they open with no warning. The Windows installer is not signed
yet: click More info, then Run anyway. Each release lists the SHA-256 of every file in `SHA256SUMS.txt`.
